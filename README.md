## 概要

本サイトは、Minecraft サーバーコミュニティ「3DS半分こするくらい仲良しクラフト」の公式ポータルサイトです。

サーバーの基本情報や参加ガイドの案内に加え、自治ルール・ルール施行令・国内法を体系的に管理・閲覧できる「ルールポータル」、および個人開発領の申請に必要な 4×4 区画マップ画像とセルフチェックツールの配布機能を提供します。

ルールポータルは「参加者が条文を迷わず確認できるアクセシビリティ」を最優先とし、デジタル庁デザインシステムをベースにした UI 設計と、一般プレイヤー向け重要条文の絞り込み切り替え機能を備えています。

## 技術構成

- **ホスティング**：GitHub Pages（`main` ブランチへの push で自動公開。独自ドメインは `CNAME` で設定）
- **ビルドエンジン**：Jekyll。ルールポータルのみ、コレクション機能で条文ページと一覧を自動生成。その他のページは静的 HTML
- **UI デザイン**：ルールポータルは[デジタル庁デザインシステム](https://design.digital.go.jp/)をベースに構成
- **外部アセット**：Google Fonts、Phosphor Icons（CDN 経由）
- 外部の依存パッケージや複雑なビルドツールの設定ファイル（Gemfile や package.json 等）はなく、素の Jekyll のみで最小限に動作します。

## 開発

### 前提環境

本番の GitHub Pages と同じ版に揃えます（GitHub Pages の[依存バージョン一覧](https://pages.github.com/versions/)に基づく）。

- Ruby 3.3.4
- Jekyll 3.10.0（`github-pages` gem v232 に同梱）

```bash
gem install github-pages -v 232
```

リポジトリに Gemfile は置いていないため、上記の gem をシステム環境にインストールして使います。本番と異なる版の Jekyll（4 系など）でビルドすると、表示が本番と食い違う場合があります。GitHub Pages 側の版は更新されることがあるため、依存バージョン一覧で最新の値を確認してください。

### ローカル実行

リポジトリのルートで以下のコマンドを実行し、ローカル開発サーバーを起動します。

```bash
jekyll serve
```

起動後、ブラウザで `http://localhost:4000/` を開きます。

### ルールの追加・改正・廃止

ルールは `_rules/` ディレクトリ配下に「1ルール1ファイル」の Markdown 形式で配置します。一覧ページはビルド時に各ファイルの front matter から自動生成されるため、一覧ページ側を手動で編集する必要はありません。

#### ファイル名規則

`R` ＋ 令和の年（2桁）＋ 種別（`01` ルール / `02` ルール施行令 / `10` 国内法）＋ 号（3桁）。
例：令和7年ルール第1号 → `R0701001.md`（公開パスは front matter の `permalink` で `.html` を指定）

#### front matter の設定例

```yaml
---
layout: rule
permalink: /rule/R0701001.html   # 公開パス
order: 1                          # 一覧での既定の並び順
title: 基本ルール                  # ページタイトル
rule_name: 基本ルール
rule_number: 令和7年ルール第1号
enforcement_date: 令和7年6月19日
category: ルール                   # ルール / ルール施行令 / 国内法
og_description: 基本ルール(令和7年ルール第1号)
---
```

#### 条文の記述ルール

ビルド時に Jekyll 標準の kramdown が HTML に変換し、`section`・`article` の囲みは条文ページのスクリプト（`_includes/rule-scripts.html`）が補います。

```markdown
## 前文

　前文の本文。

## 第1章 総則

### 第1節 禁止事項

##### 第8条（刑罰を科す権限）
{: data-general="true"}

①　国家は、国内法に違反した参加者に対して、次の各号に掲げる刑罰を科すことができます。
一　拘禁　参加者を拘束し、……
②　他ルールへのリンクは[禁止事項及び処罰に関するルール第3章](R0701002.html#第3章-処罰)のように書きます。

## 附則

##### 附則

　このルールは、公布の日から施行します。
```

- **見出し**：前文・章・附則は `##`、節は `###`、款は `####`、条は `#####` で書きます。章のないルールは条（`#####`）から書き始めて構いません。
- **一般向け条文**：条の見出しの次の行に `{: data-general="true"}` を書いた条文が、「一般向け条文のみ表示」機能の対象になります（書かなければ一般向けでない扱い）。条の見出しがない本文は常に表示されます。
- **項・号**：1行に1つ書きます。行の改行がそのまま改行として表示されます（`_config.yml` の `hard_wrap`）。
- **条文間リンク**：飛び先は見出しの文言そのまま（空白は `-`）で指定します（例：`R0701002.html#第8条（窃盗の禁止）`）。
- **注意**：行頭の `1.`・`- `・`#`・`>` や、`*`・`_` で囲んだ文字は Markdown の記法として解釈されるため避けてください。
- **廃止**：該当するルールファイルを削除します。
