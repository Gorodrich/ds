## 概要

本サイトは、Minecraft サーバーコミュニティ「3DS半分こするくらい仲良しクラフト」の公式ポータルサイトです。

サーバーの基本情報や参加ガイドの案内に加え、自治ルール・ルール施行令・国内法を体系的に管理・閲覧できる「ルールポータル」、および個人開発領の申請に必要な 4×4 区画マップ画像とセルフチェックツールの配布機能を提供します。

ルールポータルは「参加者が条文を迷わず確認できるアクセシビリティ」を最優先とし、デジタル庁デザインシステムをベースにした UI 設計と、一般プレイヤー向け重要条文の絞り込み切り替え機能を備えています。

## 技術構成

- **ホスティング**：GitHub Pages（`main` ブランチへの push で自動公開。独自ドメインは `CNAME` で設定）
- **ビルドエンジン**：Jekyll。ルールポータルとガイドは、コレクション機能で Markdown から各ページ・一覧・目次を自動生成。その他のページは静的 HTML
- **UI デザイン**：ルールポータルは[デジタル庁デザインシステム](https://design.digital.go.jp/)をベースに構成。ガイドはサイト共通のダークテーマ
- **外部アセット**：Google Fonts、Phosphor Icons（CDN 経由）
- 外部の依存パッケージや複雑なビルドツールの設定ファイル（Gemfile や package.json 等）はなく、素の Jekyll のみで最小限に動作します。

## 開発

### 前提環境

本番の GitHub Pages と同じ版に揃えます（GitHub Pages の[依存バージョン一覧](https://pages.github.com/versions/)に基づく）。

- Ruby 3.3.4
- Jekyll 3.10.0（`github-pages` gem v232 に同梱）

```bash
gem install github-pages -v 232
```

リポジトリに Gemfile は置いていないため、上記の gem をシステム環境にインストールして使います。本番と異なる版の Jekyll（4 系など）でビルドすると、表示が本番と食い違う場合があります。GitHub Pages 側の版は更新されることがあるため、依存バージョン一覧で最新の値を確認してください。

### ローカル実行

リポジトリのルートで以下のコマンドを実行し、ローカル開発サーバーを起動します。

```bash
jekyll serve
```

起動後、ブラウザで `http://localhost:4000/` を開きます。

### ルールの追加・改正・廃止

ルールは `_rules/` ディレクトリ配下に「1ルール1ファイル」の Markdown 形式で配置します。一覧ページはビルド時に各ファイルの front matter から自動生成されるため、一覧ページ側を手動で編集する必要はありません。

#### ファイル名規則

`R` ＋ 令和の年（2桁）＋ 種別（`01` ルール / `02` ルール施行令 / `10` 国内法）＋ 号（3桁）。
例：令和7年ルール第1号 → `R0701001.md`（公開パスは front matter の `permalink` で `.html` を指定）

#### front matter の設定例

```yaml
---
layout: rule
permalink: /rule/R0701001.html   # 公開パス
order: 1                          # 一覧での既定の並び順
title: 基本ルール                  # ページタイトル
rule_name: 基本ルール
rule_number: 令和7年ルール第1号
enforcement_date: 令和7年6月19日
category: ルール                   # ルール / ルール施行令 / 国内法
og_description: 基本ルール(令和7年ルール第1号)
---
```

#### 条文の記述ルール

ビルド時に Jekyll 標準の kramdown が HTML に変換し、`section`・`article` の囲みは条文ページのスクリプト（`_includes/rule-scripts.html`）が補います。

```markdown
## 前文

　前文の本文。

## 第1章 総則

### 第1節 禁止事項

##### 第8条（刑罰を科す権限）
{: data-general="true"}

①　国家は、国内法に違反した参加者に対して、次の各号に掲げる刑罰を科すことができます。
一　拘禁　参加者を拘束し、……
②　他ルールへのリンクは[禁止事項及び処罰に関するルール第3章](R0701002.html#第3章-処罰)のように書きます。

## 附則

##### 附則

　このルールは、公布の日から施行します。
```

- **見出し**：前文・章・附則は `##`、節は `###`、款は `####`、条は `#####` で書きます。章のないルールは条（`#####`）から書き始めて構いません。
- **一般向け条文**：条の見出しの次の行に `{: data-general="true"}` を書いた条文が、「一般向け条文のみ表示」機能の対象になります（書かなければ一般向けでない扱い）。条の見出しがない本文は常に表示されます。
- **項・号・号の細分**：1行に1つ書き、行頭の番号で種類が自動判定されて字下げが決まります（`_config.yml` の `hard_wrap` で行の改行がそのまま改行になります）。

  | 行頭 | 判定 | 字下げ（1行目／折り返し） |
  |---|---|---|
  | `①`〜`㊿` | 項 | 0字／1字 |
  | `一　`・`十一　` など漢数字＋全角空白 | 号 | 1字／2字 |
  | `イ　`・`ロ　` などイロハ＋全角空白 | 号の細分 | 2字／3字 |
  | それ以外 | 本文 | 項が1つだけの条（`#####` の見出しがあれば条番号がなくても条として扱う）：2字／1字。前文・附則・見出しのない本文：1字／0字 |

  字下げの単位は本文の全角1字分です。本文の行頭の全角空白は有無どちらでも同じ表示になります。ルール番号・題名・章節款の字下げも同じ単位で揃えています（`rule/style.css` の `--law-zw`）。
- **条文間リンク**：飛び先は見出しの文言そのまま（空白は `-`）で指定します（例：`R0701002.html#第8条（窃盗の禁止）`）。
- **注意**：行頭の `1.`・`- `・`#`・`>` や、`*`・`_` で囲んだ文字は Markdown の記法として解釈されるため避けてください。
- **廃止**：該当するルールファイルを削除します。

### ガイドの追加・編集

ガイドは `_docs/<タブ>/` ディレクトリ配下に「1章1ファイル」の Markdown 形式で配置します。左の章一覧・右の「このページの内容」・前後のページへのリンク・概要ページの章カードは、ビルド時（目次はページ表示時）に自動で作られるため、手動で編集する必要はありません。

#### タブ

タブは `_data/docs_tabs.yml` に、並べたい順に書きます。各タブの `id` は `_docs/` 配下のディレクトリ名、および各ページの front matter の `tab` と一致させます。`external: true` のタブ（ルール）は、ガイドの外のページへ移動するだけのタブです。

#### ファイル名と front matter

ファイル名は `<2桁の章番号>-<スラッグ>.md`（例：`04-nations.md`）、タブの概要ページは `index.md` にします。並び順はファイル名ではなく front matter の `order` で決まります。

```yaml
---
layout: doc
permalink: /docs/life/nations/   # 公開パス（/docs/<タブ>/<スラッグ>/）
tab: life                         # _data/docs_tabs.yml の id
order: 4                          # 章番号（0 はタブの概要ページ）
title: 国について知っておくべきこと
icon: flag-banner                 # Phosphor Icons のアイコン名（ph- を除く）
description: 国家の領土とディープステート、他国の国内法など。   # 概要ページの章カードと meta description に使う
---
```

タブの概要ページ（`order: 0`）には `index_cards: chapters`（章カードを並べる）を書き、必要なら「知りたいことから読む」のカードを `quicknav`（`title`・`url`・`icon` の配列）で指定します。ガイドの入口（`/docs/`）は `index_cards: tabs` でタブのカードを並べます。

#### 本文の書き方

- **見出し**：章の中の見出しは `##`、その下は `###` で書きます（ページタイトルは front matter の `title` から表示されるため、`#` は使いません）。`##`・`###` は右の「このページの内容」に載ります。見出しの id は文言そのまま（空白は `-`）です。
- **段落**：1段落を1行で書きます（`hard_wrap` により、段落の途中の改行はそのまま改行として表示されます）。
- **リンク**：ほかのページへは `/docs/life/daily/` や `/rule/R0701001.html` のようにサイト内の絶対パスで書きます（「Markdownをコピー」でコピーするとき、`https://www.ds2.uk/…` の完全な URL に置き換わります）。
- **部品**：特殊な見た目の部品は、通常の Markdown の次の行に kramdown の属性指定（`{: …}`）を書いて作ります。

  | 部品 | 書き方 |
  |---|---|
  | 注意書き（ヒント・注意・危険） | 引用（`> …`）の次の行に `{: .callout .tip}`・`{: .callout .warn}`・`{: .callout .danger}` |
  | ページ末尾の注意書き | `> **注意書き**` の次の行から本文を続け、最後の行に `{: .callout .notice}` |
  | 用語集 | 定義リスト（`用語` の次の行に `: 説明`。組ごとに空行で区切る） |
  | 要点カード | 番号付きリストの次の行に `{: .keypoints}` |
  | 手順 | 番号付きリストの次の行に `{: .steps}`（項目の下に3字下げで箇条書きを入れられる） |
  | チェックリスト | `- [ ] 項目` のリストの次の行に `{: .checklist}` |
  | 表 | 通常の Markdown の表（1列目は折り返さないため、短い見出し語を置く） |

- **注意書き**：生活ガイドの各章は、末尾にページ末尾の注意書きを書きます（「Markdownを表示」で開く元ファイルにも同じ文を残すため、レイアウトでは差し込まない）。
- **注意**：本文に Liquid のタグ（`{{ … }}`・`{% … %}`）は書かないでください。「Markdownをコピー」は元ファイルをそのまま読み込んで埋め込むため、展開後の HTML がコピーされてしまいます。

#### Markdown のコピー・表示

各ページの「LLMに質問する：」から、そのページの本文を Markdown のままコピーしたり、別タブで表示したりできます。

- **コピー**：元ファイルから front matter と `{: …}` の行を除き、先頭にページ名と出典を付けたものをクリップボードに写します。
- **表示**：GitHub 上の元ファイル（`raw.githubusercontent.com`、`_config.yml` の `docs_source_base`）を開きます。`main` に push した内容が表示されるため、push 前のローカル環境では 404 になり、push 直後は数分間古い内容が表示されることがあります。
