3DS半分こするくらい仲良しクラフトで生活するうえで知っておきたいことを、ジャンルごとにまとめたガイドです。上のタブ、または下の一覧からジャンルを選んでください。

各ジャンルは1章1ページに分かれています。最初から順に読む必要はなく、気になる章だけを読めば大丈夫です。

## 参加前・参加直後の方へ

サーバーの雰囲気と参加までの流れは、[新規参加案内](/onboarding.html)（スライド形式）で紹介しています。

## AIで要約・質問したいときは

各ページの上にある「Markdownをコピー」で、そのページの本文をMarkdown形式でコピーできます。「Markdownを表示」では、同じ本文を別のタブで開けます。お使いのAIに貼り付けて、要約や質問に使ってください。

> AIの回答は誤ることがあります。ルールに関わる判断は、必ず[ルールポータル](/rule/)の条文で確認してください。
