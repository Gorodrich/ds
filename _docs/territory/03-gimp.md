GIMPはパソコンにインストールして使う無料の高機能画像編集ソフトです。オフラインでも作業できます。この章では、[2章](/docs/territory/download/)でダウンロードした申請可能領域画像から、申請したい範囲以外を消した画像を作ります。

> インストール不要のPhotopeaを使う場合は、この章は飛ばして[4章「Photopeaで編集する」](/docs/territory/photopea/)に進んでください。
{: .callout .tip}

## 1. インストール方法

### Windowsの場合

1. ブラウザで [https://www.gimp.org/downloads/](https://www.gimp.org/downloads/) にアクセスします。
2. 「Download GIMP」（バージョン番号が書かれた大きなボタン）をクリックします。
3. ダウンロードした `.exe` ファイル（ファイル名は `gimp-` で始まり、`-setup.exe` で終わります）をダブルクリックして実行します。
4. 「このアプリがデバイスに変更を加えることを許可しますか？」と聞かれたら「はい」をクリックします。
5. インストーラーの指示に従い、「Install」「Next」などをクリックしていけば完了します（特に設定を変える必要はありません）。
6. インストール後、スタートメニューから「GIMP」を起動します。
{: .steps}

### Macの場合

1. ブラウザで [https://www.gimp.org/downloads/](https://www.gimp.org/downloads/) にアクセスします。
2. Mac用のダウンロードボタンをクリックします（Apple Silicon／Intelどちらか自分のMacに合う方を選びます。分からない場合は画面左上の「このMacについて」で確認できます）。
3. ダウンロードした `.dmg` ファイルを開きます。
4. 表示されたウィンドウの中の「GIMP」アイコンを、隣の「Applications」フォルダのアイコンにドラッグ＆ドロップします。
5. 「アプリケーション」フォルダからGIMPを起動します。初回起動時に「開発元を確認できないため開けません」と出た場合は、「システム設定」→「プライバシーとセキュリティ」を開き、「このまま開く」を選択してください。
{: .steps}

## 2. 画像を開く

1. GIMPを起動します。
2. メニューの**「ファイル」→「開く/インポート」**をクリックします。
3. [2章](/docs/territory/download/)でダウンロードした「申請可能領域画像」を選択し、「開く」をクリックします。
{: .steps}

## 3. アンチエイリアスをOFFにする（作業前に必ず設定）

1. 左側（または画面上部）のツールボックスから、使う選択ツールを選びます。おすすめは以下のいずれかです。
   - **矩形選択ツール**（四角形で選びたい場合）
   - **フリー選択ツール（投げ縄）**（自由な形・斜め線で選びたい場合）
2. ツールを選ぶと、画面左側または「ツールオプション」パネルにそのツールの設定項目が表示されます。
3. 設定項目の中にある**「アンチエイリアス（Antialiasing）」**のチェックボックスを探し、**チェックを外します（OFFにします）**。
4. 「ツールオプション」パネルが見当たらない場合は、メニューの**「ウィンドウ」→「ドッキング可能なダイアログ」→「ツールオプション」**から表示できます。
{: .steps}

> これを忘れると境界がぼやけて半透明のピクセルができ、運営botの判定で却下されます。必ず選択を始める前に確認してください。
{: .callout .warn}

## 4. 申請したい範囲だけを選択して、それ以外を透明にする

消すのは、申請したい範囲以外の**白とマゼンタの両方**です。マゼンタ（他の人がすでに個人開発領を持っている場所）は、原則としてすべて消します（色の意味は[2章](/docs/territory/download/)）。

### 方法A：申請したい範囲を選んで、周りを消す（おすすめ）

1. 選択ツール（矩形選択またはフリー選択）を使い、自分が申請したい範囲（白い部分の中の、残したい形）をなぞって選択します。マゼンタの場所は、残してよい場合（2章）でなければ選択に含めません。
   - 直線的な範囲なら矩形選択、複雑な形ならフリー選択（クリックで頂点を打っていき、最後に始点に戻ってダブルクリックすると選択が確定します）が便利です。
2. 選択できたら、メニューの**「選択」→「選択範囲を反転」**をクリックします（これで「申請したい範囲以外」が選択された状態になります）。
3. 画像にアルファチャンネル（透明を扱える状態）が設定されているか確認します。メニューの**「レイヤー」→「透明部分」→「アルファチャンネルの追加」**をクリックしてください（すでに追加済みの場合はこの項目がグレーアウトしていますが、問題ありません）。
4. キーボードの**「Delete」キー**を押します。選択されていた「申請したい範囲以外」の白とマゼンタの部分が透明になります。
5. メニューの**「選択」→「選択を解除」**をクリックして選択状態を解除します。
{: .steps}

### 方法B：消しゴムツールで直接消す

複雑な形で選択が難しい場合は、選択せずに**消しゴムツール**で直接、不要な白とマゼンタの部分を塗りつぶすように消していく方法でも構いません。この場合もツールオプションで「不透明度100%」「アンチエイリアスOFF」「硬さ（ハードネス）100%（ソフトブラシは使わない）」に設定してから使ってください。

> 残した範囲の色を塗り替える必要はありません。マゼンタを残す場合も、そのままにしておきます。塗り替えると縁に半透明のピクセルが混ざる原因になります。
{: .callout .tip}

## 5. 仕上がりを確認する

1. メニューの**「表示」→「ズーム」**で拡大し、境界部分をよく見てください。
2. 境界がギザギザ（ドット単位でくっきり）になっていればOKです。境界がぼやけて灰色っぽく見える場合はアンチエイリアスが効いてしまっているので、`Ctrl+Z`（元に戻す）でやり直してください。
3. 申請したい範囲から離れた場所に、白やマゼンタの消し忘れがないかも確かめます。消し忘れた部分も、届け出た範囲として扱われます。
{: .steps}

## 6. 面積が25万平方ブロック以内か確認する（エクスポート前に必ず実施）

書き出す前に、残した範囲（＝透明でないピクセル。申請する面積）が**250,000ピクセル（＝250,000ブロック）以内**に収まっているかを、GIMPの「ヒストグラム」機能で確認します。1ピクセルが1ブロックです。

1. ツールボックスから**「色域を選択」ツール**（メニューの「ツール」→「選択ツール」→「色域を選択」、ショートカット：`Shift + O`）を選びます。
2. ツールオプションで以下を確認・設定します。
   - **しきい値（Threshold）**：`0`
   - **アンチエイリアス**：チェックを外す（OFF）
   - **フェザー**：チェックを外す（OFF）
3. キャンバス上の、白く残っている（自分が申請したい）部分をクリックします。これで白いピクセルだけが選択された状態になります。
   - 白い範囲が1か所にまとまっていない場合（複数の飛び地がある場合）は、ツールオプションの「アンチエイリアス」の下あたりにある**「連続領域」のチェックを外す**と、離れた場所の白い部分もまとめて選択できます。
4. メニューの**「ウィンドウ」→「ドッキング可能なダイアログ」→「ヒストグラム」**を開きます（すでに開いている場合はそのパネルを見ます）。
5. ヒストグラムパネルの下側（または「統計」欄）に**「ピクセル（Pixels）」**という項目があります。これが現在選択されている範囲の合計ピクセル数です。
   - パネルのチャンネル（Value／Alphaなど）はどれを選んでいても「ピクセル」の値自体は変わりません。「Count」という項目とは別物なので混同しないよう注意してください（「Count」はヒストグラムのグラフ上で特定の明るさの範囲をドラッグして選んだときに表示される値です）。
6. マゼンタを残した場合は、選択を解除してから、マゼンタの部分を同じ手順（手順3〜5）でクリックして数え、白の数と足します。白もマゼンタも、1ピクセルが1ブロックとして数えられます。
7. 合計の数値が**250,000以下**であることを確認してください。
   - 範囲が複数のタイルにまたがる場合は、全部の画像の合計が250,000以下である必要があります。1枚ずつが250,000以下でも、合計で超えれば却下されます。
   - 250,000を超えている場合は、選択を解除（「選択」→「選択を解除」）した上で、残した範囲の一部を消す（手順4で不要な部分をさらに削除する）などして範囲を小さくし、再度この手順で確認してください。
8. 確認が終わったら、メニューの**「選択」→「選択を解除」**をクリックして選択状態を解除してから、次のエクスポート作業に進みます。
{: .steps}

## 7. PNG形式で書き出す（保存）

画像の大きさは、ダウンロードしたときの**5000×5000ピクセルのまま**にします。切り抜き・拡大・縮小をした画像は却下されます（[1章](/docs/territory/requirements/)）。

> GIMPでは「保存」と「エクスポート」が別の操作です。**必ず「エクスポート」を使ってPNGにしてください。**拡張子を `.png` に書き換えただけのファイルは、PNGとして扱われず却下されます。
{: .callout .tip}

1. メニューの**「ファイル」→「名前を付けてエクスポート」**をクリックします。
2. ファイル名を**`[地図番号]_[Minecraftのユーザー名].png`**の形式で入力します（例：地図番号が04なら、`04_` の後ろに自分のMinecraftのユーザー名を続け、最後に `.png`）。地図番号は[2章](/docs/territory/download/)でメモした2桁の数字を使います。ユーザー名は、運営botの `/whoami` で表示される名前と同じにしてください（[1章](/docs/territory/requirements/)）。
3. 保存先を選び、「エクスポート」をクリックします。
4. 「PNGとしてエクスポート」という設定画面が出てきます。画像サイズや解像度に関する項目は**一切変更せず**、そのまま「エクスポート」をクリックします。
5. 完成です。[6章「提出前のセルフチェック」](/docs/territory/checklist/)で確認してから、[5章「`/kaihatsu set` で提出する」](/docs/territory/submit/)の手順で届け出てください（4章のPhotopeaは飛ばして構いません）。
{: .steps}
