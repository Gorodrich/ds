提出前に、よくある失敗をしていないか確認してください。

- [ ] 画像がPNG形式になっているか（JPEGなど別形式で保存していないか）
- [ ] 画像の縦横ピクセルサイズを変更していないか（最初にダウンロードした画像と同じサイズか）
- [ ] 境界がぼやけていないか（アンチエイリアスがOFFになっていたか）
- [ ] 白く残っているのが「自分が申請したい範囲だけ」になっているか（消し忘れの白い部分がないか）
- [ ] **ヒストグラムで確認した白いピクセル数が250,000以下になっているか**（25万平方ブロック制限。[GIMP](/docs/territory/gimp/)・[Photopea](/docs/territory/photopea/)の手順6を参照）
- [ ] ファイルが破損していないか（提出前に一度開き直して確認する）
- [ ] **ファイル名が`[地図番号]_マイクラのユーザー名.png`（例：`04_56drich.png`）の形式になっているか**（地図番号は2桁、ダウンロード時にタイルに表示されていた番号と一致しているか）
{: .checklist}

[提出前セルフチェックツール](/tiles/checker.html)を使うと、画像の形式・サイズ・面積などを自動で確認できます。

以上の点を満たしていれば、運営側は面積の自動または簡易チェックとアップロードのみで対応できるようになります。ご協力よろしくお願いします。
