作った画像を `/kaihatsu set` で届け出る前に、よくある失敗をしていないか確認する章です。運営botは届いた画像を自動で確かめ、条件を1つでも満たしていなければ却下します。却下されたときは、満たしていない条件が①〜⑧の番号で示されます（読み方は[運営botの個人開発領の章](/docs/opsbot/kaihatsu/)の「却下されたとき」）。各項目の末尾の番号は、その条件の番号です。

## ルールの要件

個人開発領は、次の3つの要件を満たさなければなりません（旧ボーダー外の個人開発領に関するルール特例第3条）。要件の説明は[1章「必ず確認する条件」](/docs/territory/requirements/)にあります。

- [ ] **残した範囲（透明でないピクセル）の数が、全部の画像の合計で250,000以下になっているか**。個人開発領は25万平方ブロックを超えてはなりません（旧ボーダー外の個人開発領に関するルール特例第3条第1項）。数え方は[GIMP](/docs/territory/gimp/)・[Photopea](/docs/territory/photopea/)の手順6を参照。マゼンタを残したときは、その数も足します → ④
- [ ] **特定保護区域の土地を含めていないか**。個人開発領は特定保護区域内の土地を含んではなりません（旧ボーダー外の個人開発領に関するルール特例第3条第2項）。特定保護区域かどうか分からない場所は、運営に確かめてください → ⑤
- [ ] **マゼンタ（他の人の個人開発領）を消したか**。個人開発領は、すでに設定されている他の個人開発領と重なってはなりません（旧ボーダー外の個人開発領に関するルール特例第3条第3項）。マゼンタを残してよいのは、持ち主がすでに手放している場合と、持ち主から譲ってもらう手続きをする場合だけです（[2章](/docs/territory/download/)）。配布画像は2026年8月20日時点の状況なので、白い場所でもその後に他の人のものになっていないか、[Dynmap](https://map.ds2.uk/) で確かめておくと安心です → ⑥
{: .checklist}

## その他の要件

運営botが届出を自動で処理できるようにするために、画像に必要な要件です。運営botはこれらも確かめ、満たしていない画像は却下されます。

- [ ] **画像がPNG形式になっているか**（JPEGなど別形式で保存していないか。拡張子だけを `.png` に書き換えていないか） → ①
- [ ] **画像の縦横のサイズを変えていないか**（ダウンロードした画像と同じ5000×5000ピクセルのままか。切り抜き・拡大・縮小をしていないか） → ②
- [ ] **境界がぼやけていないか**（アンチエイリアスがOFFになっていたか。ソフトなブラシや、色の塗り替えで半透明のピクセルが混ざっていないか） → ③
- [ ] **ファイル名が `[地図番号]_[Minecraftのユーザー名].png` の形式になっているか**（地図番号は `04` のような2桁で、ダウンロードしたタイルの番号と一致しているか。ユーザー名は `/whoami` で表示される名前と一致しているか） → ⑦
{: .checklist}

## 届け出る前に

- [ ] **`/authorise` でDiscordのアカウントとMinecraftのアカウントを紐づけてあるか**。紐づけていないと `/kaihatsu` は使えません（[アカウントの紐づけ](/docs/opsbot/authorise/)）
- [ ] **残っているのが「自分が申請したい範囲だけ」になっているか**（離れた場所に白やマゼンタの消し忘れがないか）。消し忘れた部分も、届け出た範囲として扱われます
- [ ] **配布画像でもともと透明だった場所（旧ボーダー内など、届け出られない場所）を塗り足していないか**。塗り足した画像は運営botの判定を通ってしまうことがありますが、運営が承認を撤回する対象になります
- [ ] **範囲を変えるときは、今持っている範囲のうち残したい部分を全部含めたか**。`/kaihatsu set` は送った画像を個人開発領の全体として扱うため、画像に写っていない範囲は削除扱いになります（[5章](/docs/territory/submit/)）
- [ ] **範囲が複数のタイルにまたがるときは、全部の画像を1回の `/kaihatsu set` に添付する準備ができているか**
- [ ] **ファイルが壊れていないか**（提出前に一度開き直して、透明な部分が透明のままか確認する） → ①
{: .checklist}

[提出前セルフチェックツール](/tiles/checker.html)を使うと、画像の形式・サイズ・面積などを自動で確認できます。

確認が済んだら、[5章「`/kaihatsu set` で提出する」](/docs/territory/submit/)の手順で届け出てください。
