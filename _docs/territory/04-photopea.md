Photopeaは無料でブラウザ上で使える画像編集サービスです。ソフトのインストールが不要なので、学校のパソコンなど自由にソフトを入れられない環境でも使えます。この章では、[2章](/docs/territory/download/)でダウンロードした申請可能領域画像から、申請したい範囲以外を消した画像を作ります。

> GIMPで編集した場合は、この章は飛ばして[6章「提出前のセルフチェック」](/docs/territory/checklist/)と[5章「`/kaihatsu set` で提出する」](/docs/territory/submit/)に進んでください。
{: .callout .tip}

## 1. アクセス方法

1. ブラウザで [https://www.photopea.com/](https://www.photopea.com/) にアクセスします。
2. 特に会員登録は不要です。開くとすぐに編集画面が表示されます。
{: .steps}

## 2. 画像を開く

1. トップ画面（または左上メニュー）の**「File」→「Open」**をクリックします。
2. [2章](/docs/territory/download/)でダウンロードした「申請可能領域画像」を選択して開きます。
3. パソコンの画像ファイルをそのままブラウザ画面にドラッグ＆ドロップしても開けます。
{: .steps}

## 3. アンチエイリアスをOFFにする（作業前に必ず設定）

1. 左側のツールバーから、使う選択ツールをクリックします。おすすめは以下のいずれかです。
   - **Rectangular Marquee Tool**（四角形の選択、ショートカット：`M`）
   - **Lasso Tool** の中の **Polygonal Lasso Tool**（クリックで頂点を打って多角形に選ぶ）
   - **Magic Wand Tool**（同じ色（白）の範囲をクリック一つで選ぶ。マス目状に区切られた範囲を選びたいときに便利）
2. ツールを選ぶと、画面上部にそのツールのオプションバーが表示されます。
3. オプションバーの中にある**「Anti-alias」**のチェックボックスを探し、**チェックを外します（OFFにします）**。
4. Magic Wand Toolを使う場合は、あわせて**「Contiguous（隣接）」**にチェックが入っていることも確認してください（離れた場所の白まで一気に選ばれるのを防げます）。
{: .steps}

> これを忘れると境界がぼやけて半透明のピクセルができ、運営botの判定で却下されます。必ず選択を始める前に確認してください。
{: .callout .warn}

## 4. 申請したい範囲だけを選択して、それ以外を透明にする

消すのは、申請したい範囲以外の**白とマゼンタの両方**です。マゼンタ（他の人がすでに個人開発領を持っている場所）は、原則としてすべて消します（色の意味は[2章](/docs/territory/download/)）。

### 方法A：申請したい範囲を選んで、周りを消す（おすすめ）

1. 選択ツールを使い、自分が申請したい範囲（残したい白い部分の形）を選択します。マゼンタの場所は、残してよい場合（2章）でなければ選択に含めません。
   - Polygonal Lasso Toolの場合、クリックで頂点を打っていき、最後は始点をクリックするか `Enter` キーで選択を確定します。
2. 選択できたら、上部メニューの**「Select」→「Inverse」**（選択範囲の反転）をクリックします。
3. キーボードの**「Delete」キー**を押します。選択されていた「申請したい範囲以外」の白とマゼンタの部分が透明になります。
   - もし透明にならず白いまま消えない場合は、右側のレイヤーパネルでそのレイヤーに鍵アイコン（ロック）がかかっていないか確認し、かかっていれば解除してください。
4. 上部メニューの**「Select」→「Deselect」**で選択を解除します。
{: .steps}

### 方法B：消しゴムツールで直接消す

複雑な形の場合は**Eraser Tool（消しゴム、ショートカット：`E`）**で、不要な白とマゼンタの部分を直接消しても構いません。オプションバーで「Hardness（硬さ）」を100%に、「Anti-alias」をOFFに設定してから使ってください（ソフトなブラシは使わないでください）。

> 残した範囲の色を塗り替える必要はありません。マゼンタを残す場合も、そのままにしておきます。塗り替えると縁に半透明のピクセルが混ざる原因になります。
{: .callout .tip}

## 5. 仕上がりを確認する

1. `Ctrl` + `+`（または画面右上の拡大率表示）で拡大し、境界部分を確認します。
2. 境界がドット単位でくっきりしていればOKです。ぼやけている場合は `Ctrl + Z` でやり直してください。
3. 申請したい範囲から離れた場所に、白やマゼンタの消し忘れがないかも確かめます。消し忘れた部分も、届け出た範囲として扱われます。
{: .steps}

## 6. 面積が25万平方ブロック以内か確認する（エクスポート前に必ず実施）

書き出す前に、残した範囲（＝透明でないピクセル。申請する面積）が**250,000ピクセル（＝250,000ブロック）以内**に収まっているかを、Photopeaの「ヒストグラム」機能で確認します。1ピクセルが1ブロックです。

1. 左側のツールバーから**Magic Wand Tool（マジック棒ツール、ショートカット：`W`）**を選びます。
2. 画面上部のオプションバーで以下を確認・設定します。
   - **Tolerance（許容値）**：`0`
   - **Anti-alias**：チェックを外す（OFF）
   - **Contiguous（隣接）**：白い範囲が1か所にまとまっている場合はチェックを入れたまま、離れた場所にも白い部分が複数ある場合はチェックを外す
3. キャンバス上の、白く残っている（自分が申請したい）部分をクリックします。これで白いピクセルだけが選択された状態になります。
4. 上部メニューの**「Window」→「Histogram」**をクリックしてヒストグラムパネルを開きます。
5. パネルの右上にある小さなメニューアイコン（≡のようなアイコン、パネルメニュー）をクリックし、**「Expanded View」**（または「All Channels View」）を選択します。デフォルトの簡易表示のままだと統計の数値が表示されないことがあるためです。
6. パネル内に表示される統計欄の中から**「Pixels」**という項目を探します。これが現在選択されている範囲の合計ピクセル数です。
   - 「Count」という項目とは別物なので混同しないよう注意してください（「Count」はヒストグラムのグラフ上を実際にドラッグして特定の明るさの範囲を選んだときに表示される値です。今回は「Pixels」の値だけを見れば十分です）。
   - 数値が表示されない・更新されないなど動作が不安定な場合は、一度ヒストグラムのグラフ部分を1回クリックしてから確認し直してください。
7. マゼンタを残した場合は、選択を解除してから、マゼンタの部分を同じ手順（手順3〜6）でクリックして数え、白の数と足します。白もマゼンタも、1ピクセルが1ブロックとして数えられます。
8. 合計の数値が**250,000以下**であることを確認してください。
   - 範囲が複数のタイルにまたがる場合は、全部の画像の合計が250,000以下である必要があります。1枚ずつが250,000以下でも、合計で超えれば却下されます。
   - 250,000を超えている場合は、選択を解除（「Select」→「Deselect」）した上で、残した範囲の一部を消す（手順4で不要な部分をさらに削除する）などして範囲を小さくし、再度この手順で確認してください。
9. 確認が終わったら、メニューの**「Select」→「Deselect」**をクリックして選択状態を解除してから、次のエクスポート作業に進みます。
{: .steps}

> 参考：この確認方法はPhotoshop互換のヒストグラムパネルの仕様に基づくものです。GIMPの「ヒストグラム」ダイアログと同じ考え方（選択範囲の合計ピクセル数＝「Pixels」の値を読む）で確認できます。
{: .callout .tip}

## 7. PNG形式で書き出す（保存）

画像の大きさは、ダウンロードしたときの**5000×5000ピクセルのまま**にします。切り抜き・拡大・縮小をした画像は却下されます（[1章](/docs/territory/requirements/)）。

1. 上部メニューの**「File」→「Export as」→「PNG」**をクリックします。
2. 書き出し設定画面が表示されます。**「Width」「Height」（サイズ）の数値は最初に開いたときの数値のまま、絶対に変更しないでください。**
3. 「Export」ボタン（または「Save」ボタン）をクリックすると、パソコンにPNGファイルがダウンロードされます。ダウンロード時（または保存後のリネーム時）に、ファイル名を**`[地図番号]_[Minecraftのユーザー名].png`**の形式にしてください（例：地図番号が04なら、`04_` の後ろに自分のMinecraftのユーザー名を続け、最後に `.png`）。地図番号は[2章](/docs/territory/download/)でメモした2桁の数字を使います。ユーザー名は、運営botの `/whoami` で表示される名前と同じにしてください（[1章](/docs/territory/requirements/)）。
4. 完成です。[6章「提出前のセルフチェック」](/docs/territory/checklist/)で確認してから、[5章「`/kaihatsu set` で提出する」](/docs/territory/submit/)の手順で届け出てください。
{: .steps}
