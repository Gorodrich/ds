この章は、運営に質問や通報をしたいとき、マイクラ鯖に入れないとき、処罰に納得できないときに、どこへ・どうやって伝えればよいかをまとめています。ルールの中身は、それぞれの章（[普段の生活でできること](/docs/life/daily/)、[禁止事項一覧](/docs/life/prohibited/)など）を見てください。

## 12-1. 用件ごとの窓口

運営に伝えたいことの多くは、チケットで出します。ただし、運営bot（OpsBot。Discord上の表示名は「DSクラフト運営bot」）のコマンドでできる手続きは、チケットではなくコマンドで行います。

| 窓口 | 用件 | くわしくは |
|---|---|---|
| チケット | ルールについての質問・相談、要望・改革案 | 12-2 |
| チケット | ルール違反の通報 | 12-3 |
| チケット | 情報の開示の請求、特定保護区域で建築・採掘する承認の請求 | [普段の生活でできること](/docs/life/daily/) |
| チケット | 新しい参加者を招待する届出 | [新しい参加者を迎えるとき（招待・仮参加）](/docs/life/joining/) |
| 運営問い合わせ | 仮参加者が本参加することへの異議 | 12-7 |
| `/authorise` | アカウントの紐づけ（マイクラ鯖のホワイトリストへの追加） | [アカウントの紐づけ](/docs/opsbot/authorise/) |
| `/kaihatsu` | 個人開発領の届出・変更・削除・譲渡 | [旧ボーダー外で開発したいときは（個人開発領）](/docs/life/personal-dev/) |
| `/umetate` | 海の埋立て（護岸工事を含む）の許可の請求 | [禁止事項一覧](/docs/life/prohibited/) |
| お知らせ | マイクラ鯖に入れない | 12-4 |
| 裁判所 | 処罰の決定への異議 | 12-6 |

## 12-2. ルールについて質問したい・要望を伝えたいとき

ルールについての質問や相談、ルールや運営への要望・改革案は、チケットで運営に出せます。チケットを出すと、運営者の中で担当を決めて対応します。

「これはルール上問題ないだろうか」と迷う行為は、自分だけで判断せず、する前にチケットで運営に確かめてください。確かめるまでは、その行為を控えてください。

要望や改革案を出しても、そのとおりにルールや運用が変わると約束されるわけではありません。ルールを変えるには改正の手続きが要ります。改正の流れは[ルール改正・運営制度について](/docs/life/amendments/)にあります。

## 12-3. ルール違反を見つけたとき

マイクラ鯖でルール違反を見つけたときに、その場でまずすること（stop コマンドでの緊急閉鎖）は[普段の生活でできること](/docs/life/daily/)の 4-8 にあります。

違反は、チケットで運営に通報します。何があったかが分かるスクリーンショットなどの証拠を添えてください。

処罰するかどうかと、処罰の内容は、運営が運営の承認によって決め、執行します（禁止事項及び罰則に関するルール第16条）。通報したあとの流れは[ルール違反した場合の流れ](/docs/life/violations/)にあります。

処罰の決定に対して裁判所に異議を申し立てられるのは、運営から処罰の決定を受けた人です（禁止事項及び罰則に関するルール第17条）。通報した人が、処罰しないと決められたことや処罰の内容に対して、異議を申し立てる定めはありません。

## 12-4. マイクラ鯖に入れないとき

参加者は、次の場合を除いて、いつでもマイクラ鯖に参加できます（基本ルール第7条）。

- ルールに基づく処罰や緊急措置で、参加を禁止されている場合
- メンテナンス、緊急停止、不具合などで、マイクラ鯖が止まっている場合

マイクラ鯖に入れないときは、次の順に確かめてください。

1. 「鯖お知らせ」チャンネルを見て、メンテナンスや障害のお知らせが出ていないかを確かめます。出ていれば、お知らせにある再開の見込みや次のお知らせを待ちます。
2. 初めて入るとき、またはMinecraftのアカウントを変えたときは、運営botの `/authorise` で、DiscordのアカウントとMinecraftのアカウントを紐づけたかを確かめます。紐づけるとマイクラ鯖のホワイトリストに追加されます。紐づけの状況は `/whoami` で確かめられます（自分にだけ表示されます）。紐づけは自分では変更できないので、間違えたときは運営者に直してもらいます。くわしくは[アカウントの紐づけ](/docs/opsbot/authorise/)。
3. 統合版（Minecraft Bedrock Edition）から入るときは、Java版のアカウントとの紐づけも要ります。やり方は[新しい参加者を迎えるとき（招待・仮参加）](/docs/life/joining/)の 2-9 にあります。
4. お知らせが出ておらず、紐づけも済んでいるのに入れないときは、チケットか運営者へのDMで運営に知らせます。
{: .steps}

メンテナンスで参加者の権利を制限したとき、運営者は、遅滞なくそのことを参加者に告知し、制限の必要がなくなったらすぐに制限を解かなければなりません（基本ルール第15条第2項）。メンテナンスの開始と終了は、「鯖お知らせ」チャンネルに自動で投稿されます。

障害（思いがけない停止や不具合）が起きたときは、運営者が運営bot（`/shogai`）で「鯖お知らせ」チャンネルにお知らせを出します。お知らせには、発生日時、影響範囲、原因、復旧の見込み、ワールドデータへの影響が書かれ、状況が変わると続報、直ると復旧のお知らせが出ます。障害が始まったときと直ったときは、「お知らせ」チャンネルにも短いお知らせが出ます。お知らせの出し方（運営者向け）は[障害のお知らせとbotの管理](/docs/opsbot/shogai/)にあります。

## 12-5. 障害やメンテナンスのあと、ワールドに異常を見つけたとき

障害やメンテナンスから復旧したあと、マイクラ鯖に入ったら、自分の建築物やアイテムに異常がないかを確かめてください。異常を見つけたら、チケットで運営に知らせます。

障害の復旧のお知らせには、補填の有無と、ワールドを巻き戻した場合はどの時点まで戻したかが書かれます。異常を知らせる前に、復旧のお知らせを確かめてください。

## 12-6. 処罰に納得できないとき

参加者と国家に対する処罰は、運営の承認か、ルールに基づいて置かれる裁判所の判決に基づいて行わなければなりません（基本ルール第27条第1項）。運営が処罰を決めるときは、運営の承認によって決め、執行します（禁止事項及び罰則に関するルール第16条）。

運営から処罰の決定を受けた人は、その決定に対して、裁判所に異議を申し立てることができます（禁止事項及び罰則に関するルール第17条）。

- 異議を申し立てても、裁判所が判決するまでは、運営が決めた処罰がそのまま執行されます（禁止事項及び罰則に関するルール第17条）。
- 国家が運営から処罰を受けたときも、処罰の方法は禁止事項及び罰則に関するルールの処罰の章に準じます（国家に関するルール第18条）。
- 裁判所に関する事項は、別にルールで定めることになっています（基本ルール第27条第2項）。異議の出し方が分からないときは、チケットで運営に聞いてください。

国の国内法による刑罰（国家が科す拘禁・没収）は、運営の処罰とは別のものです。国内法に違反したと言われたときのことは[国について知っておくべきこと](/docs/life/nations/)にあります。

## 12-7. 仮参加者の本参加に異議があるとき

仮参加者が本参加することに異議があるときは、お知らせに出る仮参加の告知への返信ではなく、「運営問い合わせ」チャンネルから運営に出してください。異議を出せる期限と、出したあとの審査の流れは[新しい参加者を迎えるとき（招待・仮参加）](/docs/life/joining/)の 2-8 にあります。
