以下は「行うと処罰対象になる行為」の一覧です（禁止事項及び罰則に関するルール 第1章）。違反すると、BANや監獄への収容といった処罰が科されます。処罰が確定する前でも、緊急措置としてキックや所持品の一時没収が行われることがあります。

| 条 | 禁止事項 | 内容 |
|---|---|---|
| 第1条 | **部外者の参加** | 参加者以外を鯖に参加させる／自ら不正に参加する |
| 第2条 | **情報漏洩** | 参加者の情報を、参加者以外が見られる状態にしない |
| 第3条 | **侮辱** | 公然と他の参加者を侮辱しない |
| 第4条 | **チート・不正な権限行使** | 付与された権限を超える不正操作の禁止 |
| 第5条 | **戦争目的の加害行為** | 国家に関するルールに違反する戦争目的での加害禁止 |
| 第6条 | **無断破壊** | 他人の看板・建築物を許可なく破壊しない |
| 第7条 | **妨害目的の建築・採掘** | 他人の活動を妨害する意図での行為の禁止 |
| 第8条 | **窃盗** | 他人の財物を盗まない |
| 第9条 | **サーバーへの過剰な負荷** | 意図的にサーバーへ負荷をかける行為の禁止 |
| 第10条 | **stopコマンドの乱用** | 定められた目的以外での使用禁止 |
| 第11条 | **海の無断埋立て** | 埋立てには運営2人以上の許可が必要 |
| 第12条 | **特定保護区域での無断建築・採掘** | 運営の承認が必要 |
| 第13条 | **不正アイテムの保持・使用** | コマンド／クリエイティブ由来アイテムを、ルールや正当な職権行使による場合を除き不正に保持・使用しない |

> 共犯についての規定もあります。2人以上で共同してルール違反を行った場合は、全員が実行者として処罰されます（第14条）。そそのかしや幇助を行った者も同様に処罰対象です（第15条）。「主導したわけではない」「手伝っただけ」であっても、原則として「一緒に違反行為をした」と判断され処罰を受けるので、注意が必要です。
