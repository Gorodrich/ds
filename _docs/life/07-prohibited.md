この章は、何をしたら処罰されるのかを知りたいすべての参加者向けに、禁止事項及び罰則に関するルールが定める禁止事項と、その処罰をまとめています。禁止事項でなければ、建築・採掘やアイテムの使用は原則として自由です（[普段の生活でできること](/docs/life/daily/)）。違反したときの処罰の決め方や、違反を見つけたときの通報のしかたは[ルール違反した場合の流れ](/docs/life/violations/)にあります。

## 7-1. 何をしたら処罰されるのか（一覧）

禁止事項は、ディスコード鯖（Discordサーバー「3DS半分こするくらい仲良しクラフト中央委員会」。基本ルール第1条第1号）とマイクラ鯖の両方で禁止されているもの（禁止事項及び罰則に関するルール第1条〜第4条）と、マイクラ鯖で禁止されているもの（禁止事項及び罰則に関するルール第5条〜第13条）に分かれています。くわしい中身は 7-2 以降の節にあります。

| 禁止事項 | 処罰 | 根拠（節） |
|---|---|---|
| 参加者以外の参加 | この決まりを知っていて参加した参加者以外の人と、参加者以外を故意に参加させた参加者は、両方の鯖から永久BAN。知らずに参加した人はキック（緊急措置） | 禁止事項及び罰則に関するルール第1条（7-2） |
| 情報漏洩 | 永久または7日以上のBAN（マイクラ鯖・ディスコード鯖の一方または両方） | 禁止事項及び罰則に関するルール第2条（7-2） |
| 侮辱 | 永久または1時間以上のBAN（一方または両方の鯖）、またはディスコード鯖でのタイムアウト | 禁止事項及び罰則に関するルール第3条（7-2） |
| チート・ハッキング | 両方の鯖から、永久または30日以上のBAN | 禁止事項及び罰則に関するルール第4条（7-2） |
| 戦争目的の加害 | 両方の鯖から、永久または30日以上のBAN | 禁止事項及び罰則に関するルール第5条（7-8） |
| 無断破壊 | 7日以内のマイクラ鯖からのBAN、または監獄への収容 | 禁止事項及び罰則に関するルール第6条（7-3） |
| 妨害目的の建築・採掘 | 7日以内のマイクラ鯖からのBAN、または監獄への収容 | 禁止事項及び罰則に関するルール第7条（7-3） |
| 窃盗 | 7日以内のマイクラ鯖からのBAN、または監獄への収容。盗んだアイテムは没収 | 禁止事項及び罰則に関するルール第8条（7-3） |
| 過剰な負荷 | 妨害目的なら30日以内のマイクラ鯖からのBAN。7日以上のBANを3回以上受けると永久BAN | 禁止事項及び罰則に関するルール第9条（7-6） |
| stopコマンドの乱用 | 7日以内のマイクラ鯖からのBAN | 禁止事項及び罰則に関するルール第10条（7-6） |
| 海の無断埋立て | 7日以内のマイクラ鯖からのBAN、または監獄への収容 | 禁止事項及び罰則に関するルール第11条（7-4） |
| 特定保護区域での無断建築・採掘 | 7日以内のマイクラ鯖からのBAN、または監獄への収容 | 禁止事項及び罰則に関するルール第12条（7-5） |
| アイテムの不正な保持・使用 | 7日以内のマイクラ鯖からのBAN、または監獄への収容。そのアイテムは没収 | 禁止事項及び罰則に関するルール第13条（7-7） |
| 共犯（一緒にした・そそのかした・手伝った） | 実行した人と同じ | 禁止事項及び罰則に関するルール第14条・第15条（7-9） |

表の「監獄」は、運営が定める監獄です。国が国内法で決めている決まりは、この一覧とは別のものです。国内法については[国について知っておくべきこと](/docs/life/nations/)を見てください。

## 7-2. Discord でもマイクラ鯖でもしてはいけないこと

### 参加者でない人を参加させない

参加者でない人は、ほかに定めがない限り、ディスコード鯖にもマイクラ鯖にも参加してはいけません（禁止事項及び罰則に関するルール第1条第1項）。参加者とは、ディスコード鯖で「人民」のロールを持っている人のことです（基本ルール第1条第3号）。

- 参加者でない人を、故意にディスコード鯖やマイクラ鯖に参加させた参加者は、両方の鯖から永久にBANされます（禁止事項及び罰則に関するルール第1条第4項）。
- この決まりを知っていて参加した、参加者でない人も、両方の鯖から永久にBANされます（禁止事項及び罰則に関するルール第1条第2項）。
- この決まりを知らずに参加した、参加者でない人は、緊急措置でその鯖からキックされます。ただし、鯖や参加者に危害を加える目的で参加した人は、知っていたものとみなされ、永久BANになります（禁止事項及び罰則に関するルール第1条第3項）。

新しい人を迎えたいときは、決められた手続き（招待・面接・仮参加）を経てください。手続きは[新しい参加者を迎えるとき（招待・仮参加）](/docs/life/joining/)にあります。

### 鯖の中の情報を外に出さない

マイクラ鯖とディスコード鯖での、自分以外についてのすべての情報を、参加者でない人が簡単に見られる状態にしてはいけません（禁止事項及び罰則に関するルール第2条第1項）。違反すると、永久または7日以上、マイクラ鯖とディスコード鯖の一方または両方からBANされます（禁止事項及び罰則に関するルール第2条第2項）。

次の場合は、この禁止にあたりません（禁止事項及び罰則に関するルール第2条第1項）。

- その情報に含まれる参加者から許可を得た場合
- 雑談鯖（Discordサーバー「オールト雑談コミュニティ」。基本ルール第1条第2号）または各国家のDiscordサーバーに載せる場合

他の参加者が写っている・書かれている情報を外に出したいときは、その参加者に先に許可を取ってください。

### 他の参加者を侮辱しない

公然と他の参加者を侮辱してはいけません（禁止事項及び罰則に関するルール第3条第1項）。違反すると、永久または1時間以上、マイクラ鯖とディスコード鯖の一方または両方からBANされるか、ディスコード鯖でタイムアウトされます（禁止事項及び罰則に関するルール第3条第2項）。

### チート・ハッキングをしない

マイクラ鯖やディスコード鯖で不正な入力をして、自分に与えられた権限を超えることをしてはいけません（禁止事項及び罰則に関するルール第4条第1項）。違反すると、両方の鯖から、永久または30日以上BANされます（禁止事項及び罰則に関するルール第4条第2項）。

## 7-3. 他の参加者の建築物や持ち物に手を出すとき

マイクラ鯖では、次のことをしてはいけません。違反すると、7日以内の期間を決めてマイクラ鯖からBANされるか、運営が定める監獄に収容されます。

- 他の参加者が設置した看板・建築物を、設置した人の許可を得ずに壊すこと（禁止事項及び罰則に関するルール第6条）
- 他の参加者の活動を妨害する目的で、建築・採掘をすること（禁止事項及び罰則に関するルール第7条）
- 参加者や、参加者の集団の財物を盗むこと（禁止事項及び罰則に関するルール第8条）。盗んだアイテムは没収されます（禁止事項及び罰則に関するルール第8条第2項）

邪魔な建築物や看板があっても、自分で壊さずに、設置した人に許可を求めてください。設置した人が分からないとき、話がまとまらないときは、運営に相談してください（[困ったときは](/docs/life/help/)）。

自分の個人開発領に、開発権者（その個人開発領を届け出た人）の許可なく建てられたものの扱いには、別の定めがあります。[旧ボーダー外で開発したいときは（個人開発領）](/docs/life/personal-dev/)を見てください。

## 7-4. 海を埋め立てたいとき（護岸工事も）

海を埋め立てるときは、前もって2人以上の運営者の許可を得なければなりません（禁止事項及び罰則に関するルール第11条第1項）。許可を得ずに埋め立てると、7日以内の期間を決めてマイクラ鯖からBANされるか、運営が定める監獄に収容されます（禁止事項及び罰則に関するルール第11条第2項）。

海
: オーバーワールドで、y座標63の高さを、水ブロックか、水没した水草・昆布のブロックが覆っている領域です。人工的に設置したものと、歩けるブロックで囲まれたものは除きます（基本ルール第1条第10号）。

護岸工事（岸をブロックで固める工事）も、海を埋め立てる工事として、同じように許可を求めてください。

許可は、運営bot（OpsBot。Discord上の表示名は「DSクラフト運営bot」）の `/umetate` で求めます。

1. `/umetate` を実行し、埋め立てる範囲を、地図の画像（`image`）か文章での説明（`description`）で示します。どちらか一方は必ず入れます。
2. 運営者が要請を確認し、2人以上の運営者がOKを押すと許可が成立します。成立すると、運営botからDMで知らせが届きます。
3. 許可が成立してから、埋め立てを始めます。
{: .steps}

`/umetate` のくわしい使い方は[運営botの海の埋立ての許可の章](/docs/opsbot/umetate/)にあります。

## 7-5. 特定保護区域で建築・採掘したいとき

特定保護区域（運営が設定する、建築・採掘の利益を一部の参加者に独占されないよう守る領域）の中で建築・採掘をするときは、運営の承認を得なければなりません（禁止事項及び罰則に関するルール第12条第1項）。承認を得ずに建築・採掘をすると、7日以内の期間を決めてマイクラ鯖からBANされるか、運営が定める監獄に収容されます（禁止事項及び罰則に関するルール第12条第2項）。

承認の求め方は[普段の生活でできること](/docs/life/daily/)の「4-3. 特定保護区域で建築・採掘したいとき」にあります。

## 7-6. サーバーに負荷をかけること・stop コマンドの使い方

### 過剰な負荷をかけない

マイクラ鯖に過剰な負荷をかけて、参加者が正常に参加できない状態にしてはいけません（禁止事項及び罰則に関するルール第9条第1項）。

- 他の参加者の活動や、マイクラ鯖の正常な運営を妨害する目的で違反した人は、30日以内の期間を決めてマイクラ鯖からBANされます（禁止事項及び罰則に関するルール第9条第2項）。
- このBANのうち7日以上のものを3回以上受けた人は、マイクラ鯖から永久にBANされます（禁止事項及び罰則に関するルール第9条第3項）。

### stop コマンドは決められた目的にだけ使う

stop コマンド（マイクラ鯖を止めるコマンド）は、ルールに定める目的以外で使ってはいけません（禁止事項及び罰則に関するルール第10条第1項）。違反すると、7日以内の期間を決めてマイクラ鯖からBANされます（禁止事項及び罰則に関するルール第10条第2項）。

ルールに定める目的の一つが、ルール違反を見つけたときの緊急閉鎖です。参加者は、マイクラ鯖でルール違反を見つけたら、すぐに stop コマンドを実行して、マイクラ鯖を緊急に閉鎖するよう努めなければなりません（基本ルール第9条）。

## 7-7. コマンドやクリエイティブモードで手に入れたアイテム

コマンドや、クリエイティブモードの操作で手に入れたアイテムを、持ったり使ったりしてはいけません。ただし、ルールに定めがある場合と、運営が正当な職権で行う場合は除きます（禁止事項及び罰則に関するルール第13条第1項）。違反すると、7日以内の期間を決めてマイクラ鯖からBANされるか、運営が定める監獄に収容され、そのアイテムは没収されます（禁止事項及び罰則に関するルール第13条第2項）。

持っているアイテムが、この例外にあたるか分からないときは、使う前に運営に聞いてください（[困ったときは](/docs/life/help/)）。

## 7-8. 戦争のために、他の参加者や建築物に危害を加えること

国家に関するルールに違反する戦争をする目的で、害意をもって他の参加者や建築物に危害を加えてはいけません（禁止事項及び罰則に関するルール第5条第1項）。違反すると、マイクラ鯖とディスコード鯖の両方から、永久または30日以上BANされます（禁止事項及び罰則に関するルール第5条第2項）。

国家どうしの戦争がルールでどう禁止されているかは、[国について知っておくべきこと](/docs/life/nations/)の「5-6. 戦争は禁止されている」にあります。

## 7-9. 一緒にした・そそのかした・手伝っただけでも処罰される

> 2人以上で一緒にルール違反をした人は、全員が実行した人として処罰されます（禁止事項及び罰則に関するルール第14条）。ほかに定めがない限り、他の人にルール違反をするようそそのかした人や、他の人のルール違反をしやすくした（手伝った）人も、全員が実行した人として処罰されます（禁止事項及び罰則に関するルール第15条）。「自分が言い出したわけではない」「手伝っただけ」でも、処罰は実行した人と同じです。
{: .callout .warn}

誘われたことがルール違反にあたるか分からないときは、手を貸す前に運営に聞いてください（[困ったときは](/docs/life/help/)）。

## 7-10. 違反してしまった・違反を見つけたとき

違反を運営に通報する方法、処罰が決まるまでの流れ、処罰が決まる前の緊急措置、違反で変えられた地形や建築物の扱いは、[ルール違反した場合の流れ](/docs/life/violations/)にあります。処罰の決定に納得できないときの対応は[困ったときは](/docs/life/help/)にあります。
